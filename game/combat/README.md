# Sistemas de combate

- `legacy_turn_based/`: **ANTIGUO**, combate por turnos / barras de acción. Implementación completa conservada.
- `action/`: destino del combate de acción en tiempo real. **Todavía no hay implementación de combate de acción en esta rama**.
- Los archivos `game/combat/combat_*.py` son adaptadores de compatibilidad para que los imports existentes sigan funcionando.

No confundir el sistema de barras de acción del combate antiguo con el combate libre en tiempo real previsto para Unity.
